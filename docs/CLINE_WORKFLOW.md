# Cline workflow

1. Use Plan mode before substantial work.
2. Ask for one milestone at a time.
3. Review commands, dependency changes, and diffs before approving.
4. Run tests and verify actual results.
5. Commit a known-good checkpoint.
6. Do not let the LLM execute arbitrary SQL, Python, shell, or filesystem operations in the finished application.

See `.clinerules/` for persistent workspace instructions.
